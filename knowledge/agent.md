# AI Agent 基础（示例知识库）

AI Agent 通常指能够自主决定下一步行动的 LLM 应用。最常见的范式是 ReAct：模型先推理，再决定是否调用工具，拿到工具结果后继续推理，直到得出最终答案。

工具调用（function calling）是 Agent 的基础能力。开发者向模型描述可用工具的名称、用途和参数，模型返回结构化的调用请求，由程序执行工具并把结果回传给模型。

多 Agent 系统常见的组织方式有 Supervisor 模式（一个调度者分配任务给多个专家）、流水线模式和分层模式。LangGraph 通过子图和 Send 实现这些模式。

Agent 落地的主要挑战包括：输出不稳定、工具调用出错、上下文过长、成本和延迟、以及效果难以评估。常见对策是加入重试、人工审核、消息裁剪或摘要、链路追踪和离线评测集。

在国内，企业常用 DeepSeek、通义千问等模型通过兼容 OpenAI 的接口接入 Agent 框架，同时也会使用 Dify、Coze 等低代码平台快速搭建应用。
